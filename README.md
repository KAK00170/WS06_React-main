# WS06 React

WS06 on harjoitus, jossa rakennetaan React-pohjainen frontend ja Node.js + REST API -backend, jotka toimivat yhdessä.

## Tehtävän tavoite

Rakentaa REST API backend, joka käsittelee postauksia (/api/posts).
Luoda React-frontend, joka hakee ja näyttää dataa backendista.
Harjoitella CRUD-toimintoja
